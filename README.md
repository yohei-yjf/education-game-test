# 🚦 しんごうゲーム

4〜5歳の子ども向けの「ベストな信号を考えてみよう」ゲームです。
文字は使わず、絵と絵文字だけで遊べます。信号をいじって車を走らせ、
実際の信号が今の動きになっている理由を体験で学びます。

**遊ぶ:** https://yohei-yjf.github.io/education-game-test/

## ステージ

| ステージ | 学ぶこと |
| --- | --- |
| 1 🚦 | 縦が青なら横は赤。両方青にすると 💥 ぶつかる。両方赤だとみんな 😴 |
| 2 🟡 | 黄色がないと止まりきれない車が交差点に残って 💥。黄色を足すと安全 |
| 3 ↲ | 右折信号がないと右折の車が曲がれず 😢。矢印信号を足すと曲がれる |
| 4 🛣️ | 右折レーンがないと右折待ちの後ろで直進車が 😠。レーンを足すと流れる |
| 5 🏆 | 黄色・矢印・レーンを全部組み合わせてベストな信号をつくる |

## 操作

- 下のボタンで信号やレーンを切り替える
- ▶ を押すと車が走り出す
- 結果(💥 / 😢 / 😠 / ⭐ / 🎉)が出たら 🔁 でやり直し、または ▶ で次のステージへ
- 上の丸いボタンでステージを選ぶ(クリアすると次が開く)

## 開発

静的ファイルのみ(ビルド不要)。

```
python3 -m http.server 8000   # http://localhost:8000 で開く
node test/run.js              # シミュレーションのシナリオ検証
```

- `sim.js` … 交差点シミュレーション(車・信号・衝突判定)。描画に依存しない
- `stages.js` … 各ステージの設定
- `game.js` … 描画・UI・効果音
- `index.html` / `style.css` … 画面
